### 1.2 配色原則 v3
1. **黑白灰打底，橘色只標「重點」**：版面約 80% 黑白灰；橘色只出現在「需要被注意的那一個」——本公司、過門檻的分數、Tier 1、選取中的項目。
2. **一張圖只亮一個重點**：比較型圖表預設全部灰色（`--gray-400`），只把重點（本公司、最新 3 個月、Tier 1）上 `--orange-600`。參考圖一的長條圖與 Orbix 的成長率長條就是這個用法。
3. **橘色深淺＝優先度／強度**：Tier 1 `#FF5A06` → Tier 2 `#FD9832` → Tier 3 `#F8CB9F` → 暫緩 `#D9D9D9`；熱度圖也用同一條階梯。
4. **奶油色＝AI**：Copilot 面板與所有 AI 產生的區塊用 `--orange-50` 底，讓「系統算的」與「AI 寫的」分得開（取代 v2 的靛紫）。
5. **黑色＝最重要的一張卡**：每頁最多一張黑色主卡（總覽的 KPI 帶、帳戶頁的 Tier 主卡），黑底上的關鍵數字用 `--orange-400`（對黑底約 9.7:1）。
6. **對比底線**：文字 ≥ 4.5:1；圖形元素 ≥ 3:1。
   - 橘色文字一律 `--orange-700`
   - `#FD7632`、`#FD9832`、`#F2A722`、`#F8CB9F` 對白底都低於 3:1，當圖形時要**加 1px `--ink-900` 外框**或搭配形狀編碼
   - 所有橘色系底色上的文字用 `--ink-900`（對比皆 ≥ 6:1）
7. **分數變化不用紅綠**：▲▼＋數字；上升 `--orange-600`、下降 `--ink-500`。

- 側欄底部固定「資料更新卡」（取代 v2 頁首灰色橫條）：`--gray-100` 底圓角卡片，顯示 `2026-W42・規則 v2`、上次更新時間、「下次更新：週一 05:00」

### 3.4 卡片
