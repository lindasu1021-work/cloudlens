# Step 3：呈現方式與配色原則（v1 定案，2026-10-11）

## 1. 已定案的呈現決策
- 風格：企業工具風（白底、單一互動強調色、資訊密度偏高，參考 Salesforce 類 B2B 工具）
- 不使用 AWS Logo，也不模仿 AWS 主控台外觀
- 介面語言：中文
- 裝置：桌機為主（最小設計寬度 1280px；手機可瀏覽，不追求完整操作）
- 頁面：總覽儀表板／帳戶頁／方法論／資料狀態
- 象限圖：點依「主 Play」上色，並以形狀作為第二編碼（色弱友善）

- 資料區域一律平塗，不用漸層（漸層會讓圖表數值難以比較，也會降低工具感）。

## 3. 配色原則

1. **80 / 15 / 5 法則**：中性色 ≥80%、靛紫約 15%、橘 ≤5%。橘色一多就失去「注意」的意義。
2. **單一互動色**：凡是可以點的東西（按鈕、連結、選取狀態、篩選器）都是靛紫；橘色永遠不能點，只負責標示。使用者看顏色就知道哪裡可操作、哪裡要注意。
3. **橘色 = 業務該行動的地方**：Tier 1、本週新事件、分數上升。一個畫面上若有超過 5 個橘色元素，代表規則需要收斂。
4. **文字對比 ≥ 4.5:1**：參考圖的 `#A6A6A6`、`#E5832F`、`#6B6FD4` 對白底都不夠，不可直接當小字顏色；文字分別改用 `ink-500`、`orange-700`、`indigo-700`。
5. **有色底配同色系深色字**：`indigo-100` 底配 `indigo-900` 字、`orange-100` 底配 `orange-700` 字；不用黑字壓在色塊上。
6. **分數變化不用紅綠色**：台股慣例紅漲綠跌，西方相反，容易誤讀。改用 ▲▼ 箭頭＋數字；上升用 `orange-500` 箭頭，下降用 `ink-500`。
7. **錯誤／成功狀態色只在「資料狀態」頁出現**：錯誤 `#C0392B`、成功 `#2E7D5B`（衍生色，不屬於品牌色，其他頁面不使用）。

## 4. 元件配色對照

| 元件 | 配色 |
|---|---|
| 頂部導覽列 | `indigo-900` 底、白字；目前頁面以白色底線標示 |
| 主要按鈕 | `indigo-700` 底、白字；hover `indigo-900` |
| 次要按鈕 | 白底、`gray-200` 框、`ink-900` 字；hover `gray-50` |
| KPI 卡 | `gray-50` 底、`ink-500` 標籤、`ink-900` 數字 |
| 表格 | 表頭 `gray-50` 底＋`ink-600` 字（工具風不用整排深色表頭）；斑馬紋 `white`／`gray-50`；選取列 `indigo-100` |
| Tier 標章 | Tier 1：`orange-100` 底＋`orange-700` 字；Tier 2：`indigo-100` 底＋`indigo-900` 字；Tier 3：`gray-50` 底＋`ink-600` 字；暫緩：白底＋`gray-200` 框＋`ink-500` 字 |
| 雲端現況標籤 | 一律中性（`gray-50` 底＋`ink-600` 字），不搶 Tier 的注意力 |
| 訊號編號 [S1] | `indigo-700` 文字連結；hover 時左側時間軸對應訊號亮起 `indigo-50` 底 |
| Copilot 回覆框 | `indigo-50` 底、`ink-900` 字；展示模式標籤 `gray-50` 底 |

## 5. 圖表配色

### 5.1 象限圖：依主 Play 上色＋形狀
| Play | 顏色 | 形狀 |
|---|---|---|
| Migration | `indigo-900` `#2F1A7A` | 圓形 ● |
| Data | `indigo-500` `#6B6FD4` | 方形 ■ |
| GenAI | `orange-400` `#EA9C38` | 三角 ▲ |
| Security | `orange-700` `#B35F12` | 菱形 ◆ |

- 同色系的兩個 Play 靠明度區分（一深一淺），再加上形狀，色弱也看得懂。
- 象限分隔線 `gray-200` 虛線；象限名稱 `ink-500`；Tier 1 象限加 `orange-100` 極淡底色。
- 滑過某點：其他點降到 30% 透明度，顯示公司名、Need、Timing。

### 5.2 其他圖表
- 單一系列（分數條、趨勢線）：`indigo-500`
- 分數拆解條：已得分 `indigo-500`、未得分 `gray-50`；資料缺漏的項目用斜線紋＋「無資料」字樣（不是 0 分）
- 多系列順序：`indigo-900` → `indigo-500` → `orange-400` → `orange-700` → `ink-500` → `gray-400`

## 6. 字體
- 中文：Noto Sans TC（Google Fonts；對應文件規範的「微軟正黑體 → 思源黑體」）
- 數字：同字體，開啟等寬數字（`font-variant-numeric: tabular-nums`），表格欄位才對得齊
- 字級（網頁）：頁面標題 22px／區塊標題 16px／內文 14px／表格 13px／說明 12px（最小 12px）
- 粗細只用兩種（400 一般、700 粗體），避免層級過多
