# BD Side Project — 決策紀錄

> 每輪討論的結論累積在這裡，最後收斂成交給 Claude Code 的規格書（spec.md）。
> 狀態：✅ 已定案　🟡 待確認　⏳ 尚未討論

## 專案一句話
以公開資料為帳戶打分數並標出切入劇本（Play），協助 AWS 業務決定「先打誰、拿什麼去談」，再用 AI 產出帳戶簡報與破冰信草稿。
